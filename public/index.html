Fluent CSS Framework

This page is the living style guide and component reference: as tokens and components are built out (see PLAN.md), add a demo section for each one here. It automatically follows your OS light/dark setting; add data-theme="dark" or data-theme="light" on <html> to force a theme. See README.md for the full theming/rebranding guide.

Getting started

This framework ships as plain CSS with no required build step to consume it. Until it's published to npm (see PLAN.md's Stage 10), include it by building and copying the compiled file into your own project:

  1. Run npm run build:min in this repo.
  2. Copy dist/fluent.min.css into your project.
  3. Link it in your HTML <head>, before any of your own stylesheet overrides.
<link rel="stylesheet" href="fluent.min.css" />

Every class is prefixed fluent- so it can coexist with an existing project's CSS. Each section below has copyable markup for that component.

Button groups

.fluent-btn-group joins a row of buttons into one segmented control — flush borders, only the outer corners rounded. No extra class is needed on the buttons themselves. 

<div class="fluent-btn-group" role="group" aria-label="Alignment">
  <button class="fluent-btn fluent-btn--secondary">Left</button>
  <button class="fluent-btn fluent-btn--secondary">Middle</button>
  <button class="fluent-btn fluent-btn--secondary">Right</button>
</div>

<!-- mix fluent-btn--primary + aria-pressed for a segmented toggle group -->

Dialog & panel

Delete item?

This can't be undone. The item will be permanently removed.

Settings

Panels dock to an edge and use an acrylic (translucent, blurred) surface — try it over the colorful content above.

 
<dialog id="my-dialog" class="fluent-dialog">
  <h3 class="fluent-dialog__title">Delete item?</h3>
  <p class="fluent-dialog__body">This can't be undone.</p>
  <div class="fluent-dialog__actions">
    <button onclick="myDialog.close()">Cancel</button>
  </div>
</dialog>

<script>
  document.getElementById("my-dialog").showModal();
</script>

<!-- .fluent-panel uses the same <dialog>+showModal() pattern,
